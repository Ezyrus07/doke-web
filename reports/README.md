# Generated reports

This directory is reserved for short-lived local audit and visual QA outputs.

Generated artifacts such as screenshots, large JSON/CSV reports and before/after logs must not be treated as architecture. Keep permanent decisions in `docs/` and keep generated outputs out of Git unless a reviewer explicitly asks for a small evidence file.

Default generated output location:

```txt
reports/generated/
```

`reports/generated/` is intentionally ignored by Git.
