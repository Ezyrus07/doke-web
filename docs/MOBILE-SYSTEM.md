# Doke mobile system

## Regra base
- Header global claro (`#ffffff`)
- Main interno com fundo levemente distinto (`#f4f7fa`)
- Cards e superfícies em branco

## Tipos de header mobile
1. **Listagem**: pedidos, notificações, resultados
   - título + badge
   - ações compactas à direita
   - busca expansível
2. **Dashboard**: home, perfil
   - título + badge
   - ações secundárias em ícones
3. **Detalhe**: páginas profundas
   - voltar + título + ação principal

## Objetivo
Padronizar hierarquia visual e compactação sem fazer cada HTML inventar um topo diferente.
