# Mock Beta Option Package Runbook

Purpose: define the fast mock/localStorage beta option without pretending it is backend-real.

## Commands

```bash
npm run audit:mock-beta-option-package
npm run execute:mock-beta-option-package:dry-run
npm run execute:mock-beta-option-package:check-env
npm run execute:mock-beta-option-package:report
```

Mock beta can validate UX, flow comprehension, first user feedback, and visual polish. It must not be marketed as a real transactional backend launch.
