## Rules for using this matrix

- Do not delete CSS only because its filename is bad. First prove whether it is directly linked, imported by active CSS, or safely replaced.
- Treat multiple files claiming the same authority group as a consolidation candidate, not as permission to add a later override.
- Start with `index.html`/home when addressing mobile first paint, rails, workers, or route transition perception.
- For shell/router/header work, run the required viewport checks from `AGENTS.md`.
