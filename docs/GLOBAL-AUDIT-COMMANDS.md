# Global Audit Commands

## Baseline

- `npm run audit:active-contracts-index`
- `npm run audit:docs-primary-index`

## Produto

- `npm run audit:product-pages`

## Dívida estrutural

- `npm run audit:global-structural-debt`

## Design system CSS

- `npm run audit:global-css-design-system`

## Estados e data-ready

- `npm run audit:global-data-ready-states`
- `npm run audit:global-state-completion`

## Fechamento global

- `npm run audit:global-completion`

## Final readiness

- `npm run audit:visual-manifest-coverage`
- `npm run audit:global-final-readiness`
- `npm run audit:global-final`

## Observação

Este registro mantém os comandos descobríveis. Ele não substitui validação visual local com browser. Para a execução visual completa, consulte `docs/CODEX-VISUAL-VALIDATION-HANDOFF.md`.
