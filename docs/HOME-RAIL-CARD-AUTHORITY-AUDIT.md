## Architectural reading

1. The next phase must not add a new override file. It must remove duplicate authority from existing files.
2. The riskiest cleanup area is not naming anymore; it is target/property ownership for rails and cards.
3. Any move from page CSS to component CSS must preserve the approved desktop/tablet/mobile visuals.
4. Before removing a declaration, compare direct URL and `DokeNavigate('/index.html')` behavior.
5. A valid cleanup reduces collision count or `!important` count without changing the approved layout.
