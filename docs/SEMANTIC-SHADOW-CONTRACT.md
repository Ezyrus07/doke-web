# Semantic shadow contract

Semantic shadows describe meaning, not layout geometry.

- `--doke-shadow-action-primary-strong`: primary calls to action.
- `--doke-shadow-action-success-strong`: success/confirmation actions.
- `--doke-shadow-action-success-card`: marketplace success CTA.
- `--doke-shadow-action-success-active`: active success-colored selector.
- `--doke-shadow-status-primary`: compact primary status mark.
- `--doke-shadow-status-success-soft`: low-emphasis success status.
- warning and danger soft tokens are reserved for equivalent semantic states.

Do not use these tokens for static cards, panels, tabs, chips, badges, or internal icon buttons. Those remain governed by the visual hierarchy contract.
