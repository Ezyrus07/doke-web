# Private Beta Report Interpreter Runbook

## Purpose

Interpret the workstation, visual, quality, staging, and real-entry reports generated by the private beta evidence workflow into one actionable GO/NO-GO summary.

This runbook does not change HTML, CSS, layout, staging, users, or production. It only reads JSON reports and produces an evidence interpretation report.

## Commands

```bash
npm run audit:private-beta-report-interpreter
npm run execute:private-beta-report-interpreter:dry-run
npm run execute:private-beta-report-interpreter:check-env
npm run execute:private-beta-report-interpreter:report
```

## Human approval

After reading the generated action queue, approve the interpretation only when the report reflects the true state of the workstation evidence:

```bash
DOKE_PRIVATE_BETA_REPORT_INTERPRETER_APPROVED=1 \
DOKE_REPORT_INTERPRETER_REVIEWER="Gabriel" \
npm run execute:private-beta-report-interpreter:report
```

## Expected blocked state

Without real screenshots, Lighthouse/a11y, staging seeds and private beta confirmation, the expected status is:

```txt
private_beta_report_interpreter_no_go
```

## Accepted state

The accepted state for downstream gates is:

```txt
private_beta_report_interpreter_ready_for_entry_gate
```
