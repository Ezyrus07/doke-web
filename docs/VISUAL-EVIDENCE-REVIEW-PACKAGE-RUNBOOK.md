# Visual Evidence Review Package Runbook

## Objective
Package screenshot and layout-health evidence generated by `tests/visual/doke-visual-evidence.spec.js` for manual private beta review.

## Evidence expected
The manifest currently requires every priority page across every required viewport. Each item must produce:

- `<page>.png`
- `<page>.layout.json`

Default root:

```txt
reports/generated/visual-evidence
```

## Commands

```bash
npm run audit:visual-evidence-review-package
npm run execute:visual-evidence-review-package:dry-run
npm run execute:visual-evidence-review-package:check-env
npm run execute:visual-evidence-review-package:report
```

After a real human review:

```bash
DOKE_VISUAL_REVIEW_APPROVED=1 \
DOKE_VISUAL_REVIEWER="Gabriel" \
npm run execute:visual-evidence-review-package:report
```

## Approval rule
The package is blocked until screenshots and layout reports are complete and a reviewer explicitly approves the evidence.
