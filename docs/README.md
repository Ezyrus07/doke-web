# Doke docs

This directory contains only living project contracts. Historical phase notes, generated manifests, validation dumps and temporary audit reports must not live here.

## Primary contracts

- `DOKE_AGENT_CONSTITUTION.md` — mandatory agent and repository rules.
- `AGENT-REFORM-PROTOCOL.md` — how agents should approach structural work.
- `ARCHITECTURE.md` — frontend layer responsibilities.
- `PROJECT-STRUCTURE.md` — directory and ownership map.
- `CSS_AUTHORITY_MAP.md` — CSS authority boundaries.
- `BASELINE-VISUAL-APPROVED.md` — protected visual baseline.
- `HOME-AUTHORITY-CLASSIFICATION.md` — current home authority status.
- `PAGE-ASSET-AUTHORITY-MATRIX.md` — generated summary of page asset ownership.
- `DATA-READY-CONTRACTS.md` — data, API, backend, fallback and state readiness.
- `VALIDATION.md` and `QUALITY-GATES.md` — validation requirements.

## Generated reports

Generated reports belong in `reports/generated/` and should remain ignored by Git. A report can guide a change, but it is not architecture.

## Rule

If a document describes only a past phase, remove it or promote the actual decision into one of the living contracts above.
