# Checklist de performance e SEO

## Performance
- Imagens otimizadas
- Lazy loading
- CSS crítico limpo
- Bundle budget
- Menos CSS legado
- Skeleton para listas
- Paginação/infinite scroll controlado
- Lighthouse CI

## SEO
- Title e description por página
- Open Graph
- Schema.org para serviços locais
- Sitemap
- Robots.txt
- URLs amigáveis
- Páginas públicas de serviço/profissional/cidade
- Conteúdo principal indexável
